# Corn Agent

> ⚠️ **Work in Progress** — currently under active development.

A Windows x64 Mythic C2 agent written in C.

## Overview

Corn is a lightweight implant for the [Mythic C2 framework](https://github.com/its-a-feature/Mythic). It communicates with the Mythic TeamServer over HTTP/HTTPS using a custom binary protocol.

## Requirements

- Windows 10 x64
- Visual Studio 2022
- Mythic C2 server

## Usage

1. Install the HTTP C2 profile on your Mythic server
2. Build the agent
3. Execute on target
4. Callback appears in Mythic UI
